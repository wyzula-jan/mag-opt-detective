Keyboard shortcuts

On macOS, Ctrl is ⌘ and Alt is ⌥. In the app, Help › Shortcuts lists them too.

Files and processing

KeysAction
Ctrl+LOpen the field files of a sample sweep
Ctrl+Shift+LLoad sample zero-field files
Ctrl+ROpen the field files of a reference sweep
Ctrl+Shift+RLoad reference zero-field files
Ctrl+Return or Ctrl+FProcess

Plots

KeysAction
Ctrl+1Plot R(B)/R(0)
Ctrl+2Plot the data
Ctrl+3Plot R(B)/R(B-AVR)
Ctrl+4Plot R(B)/R(B-ΔB)
Alt+1 / 2 / 3No derivative / 1st / 2nd derivative
AFit the plot to the data

Tools and points

KeysAction
VPan and zoom
ZBox zoom
PPick points: a click records a point, Alt-click removes one
WAuto-pick: follow a clicked line, or find the lines in a drawn region
EscLeave the Pick or Auto-pick tool (and drop an auto-pick preview)
Ctrl+ZUndo a point edit
Ctrl+Shift+ZRedo a point edit

Export

KeysAction
Ctrl+EExport the map shown as a data table
Ctrl+Shift+EJournal figure (PDF, SVG, EPS, PNG, TIFF)

Mouse

WhereAction
Drag on a plotPan (Box zoom: zoom to the rectangle; Detect: draw a region, or move and reshape it)
Wheel over a plot or an axisZoom
Double-click on a plotFit the plot to the data (not while picking)
Alt-clickRemove a picked point (Pick tool)
Click on a scale's handleSlide that colour scale away or back
Drag between a slider's handlesMove the whole view range, keeping its width (Shift+arrow keys)

The tool letters work in the whole window, except while you type in a field or browse a list or table, which keep the letters for themselves. Tab moves through the toolbar, the panels, the plots and the inspector in order.
