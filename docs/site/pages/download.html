Opening the app the first time

The apps are not code-signed, so macOS and Windows ask once whether you trust them.

macOS

  1. Double-click the zip to unpack it and move Magneto-Optical Detective.app to your Applications folder.
  2. Right-click (or Control-click) the app, choose Open, and confirm with Open. Later launches work as usual.
  3. On macOS 15 and newer that dialog has no Open button. Double-click the app once, then open System Settings › Privacy & Security, scroll to the message about Magneto-Optical Detective and choose Open Anyway.

If macOS still refuses, or says the app “is damaged”, remove the quarantine flag that the browser put on it, in Terminal:

xattr -dr com.apple.quarantine "/Applications/Magneto-Optical Detective.app"

Windows

  1. Right-click the zip, choose Extract All…, and keep the extracted mag-opt-detective folder together: the program needs the files next to it.
  2. Start mag-opt-detective.exe in that folder.
  3. If Microsoft Defender SmartScreen says “Windows protected your PC”, choose More info, then Run anyway.

Linux

tar -xzf mag-opt-detective-linux.tar.gz
./mag-opt-detective/mag-opt-detective

If it does not start and the terminal mentions the Qt platform plugin “xcb”, install the XCB cursor library (on Ubuntu and Debian: sudo apt install libxcb-cursor0).

Good to know

  • The first Journal figure… export after installing takes about 20 s while matplotlib builds its font cache. The cache is kept, so later exports start at once (where it is kept).
  • To check an installation from a terminal, start the program with --smoke-test: it processes a small synthetic measurement, saves a figure in every format and exits with 0. On macOS the program is inside the app: 
    "/Applications/Magneto-Optical Detective.app/Contents/MacOS/mag-opt-detective" --smoke-test

Updates

Once a day, a few seconds after it starts, the app asks GitHub whether a newer version has been released. If there is one, a bar above the plot says so, with Download, Release notes and Skip this version (a version after the skipped one shows again). The app never installs anything itself: download the new version and replace the app as above; the settings are kept outside the app. Run from source, update with git pull and uv sync.

The check is one anonymous request to GitHub's releases API: no account, no cookies and nothing about you or your data, only the app's version; GitHub sees your IP address, as for any web page. Without a connection the app says nothing. Help › Check for updates… checks at once and says what came out, and Help › Check for updates at startup switches the daily check off. Until version 1.0.0 every release is a pre-release on GitHub, and the app counts them; from 1.0.0 on it offers regular releases only.

Run from source with uv

This works on every computer that runs Qt 6, including Intel Macs, and gives you the newest development state. You need git and uv; uv downloads a matching Python (3.12 or newer) if you do not have one.

git clone https://github.com/wyzula-jan/mag-opt-detective.git
cd mag-opt-detective
uv sync
uv run mag-opt-detective

uv run python -m mag_opt_detective starts it too. To update later, run git pull and uv sync in the same folder.

Build the app yourself

The standalone apps are built with PyInstaller. In a source checkout, without the development tools:

uv sync --locked --no-default-groups --group bundle
uv run --no-sync pyinstaller packaging/mag-opt-detective.spec --noconfirm

The result is in dist/. Run uv sync afterwards to get the development tools back; CONTRIBUTING.md has the details.
