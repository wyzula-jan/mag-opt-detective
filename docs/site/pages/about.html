About

Magneto-Optical Detective is a desktop app to plot, pick, fit and export magneto-optical FTIR measurements: field sweeps recorded with Bruker OPUS.

Author

Jan Wyzula.

How to cite

If you use Magneto-Optical Detective for an analysis in a publication, please cite it with the version you used, which the About box shows (Help › About, on macOS in the app menu). The repository has a CITATION.cff file, and GitHub offers it in APA and BibTeX under Cite this repository.

J. Wyzula, Magneto-Optical Detective, version x.y.z, https://github.com/wyzula-jan/mag-opt-detective

@software{wyzula_magneto_optical_detective,
  author  = {Wyzula, Jan},
  title   = {Magneto-Optical Detective},
  version = {x.y.z},
  url     = {https://github.com/wyzula-jan/mag-opt-detective},
  license = {GPL-3.0-only}
}

Source, issues and contributing

  • Source code on GitHub
  • Report a bug or ask for a feature in the issue tracker
  • CONTRIBUTING.md: setting up, the checks, the architecture and the commit conventions
  • Releases and the release notes

In the app, Help › Report a bug… opens the bug form in your web browser with the app's version, how it runs (standalone app or from source), your system, the Python, Qt and library versions and the plot shown already filled in; no file names, paths or data, and nothing is sent until you submit the form. Add what you did, what you expected, what happened and what the log says (the Log button in the status bar). The log shows full file paths: remove any paths or names you do not want public before you paste it. Never attach measurement data you cannot share; a few lines of a file usually show the problem. Help › Request a feature… opens the feature form, and Help › Documentation (F1, on macOS also ⌘+?) this site.

About the screenshots

Every screenshot on this site shows a made-up Landau fan, not a measurement. They are drawn by the app itself from synthetic files by docs/make_screenshots.py in the repository.
