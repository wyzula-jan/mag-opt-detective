About

Magneto-Optical Detective is a desktop app to plot, pick, fit and export magneto-optical FTIR measurements: field sweeps recorded with Bruker OPUS.

Author

Jan Wyzula. Versions up to 4.9 were PyQt5 scripts; version 5 rewrites them as an app.

Source, issues and contributing

  • Source code on GitHub
  • Report a problem or ask for a feature in the issue tracker
  • CONTRIBUTING.md: setting up, the checks, the architecture and the commit conventions
  • Releases and the release notes

When you report a problem, please give the app's version (Help › About), your system, and what the log says (the Log button in the status bar). Never attach measurement data you cannot share; a few lines of a file usually show the problem.

About the screenshots

Every screenshot on this site shows a made-up Landau fan, not a measurement. They are drawn by the app itself from synthetic files by docs/make_screenshots.py in the repository.
