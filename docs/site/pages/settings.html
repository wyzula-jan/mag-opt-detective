Settings and files

Where the app keeps what it remembers, and what the files it reads and writes look like.

Settings

The app remembers your choices between sessions: the unit, the plot and derivative, the ranges, colour maps and levels, the window layout and panel sizes, the processing options, the models, the auto-pick options, the journal figure settings and whether to check for updates at startup (with a version you skipped). Energies are stored in cm⁻¹, whatever unit is shown.

It does not keep the files you loaded, the picked points or the library: export the points (point tables) and the maps (data tables) to keep them.

View › Reset settings brings back the defaults. The settings are stored where Qt keeps them on each system:

SystemSettings
macOS~/Library/Preferences/com.mag-opt-detective.mag-opt-detective.plist
Windowsthe registry, under HKEY_CURRENT_USER\Software\mag-opt-detective\mag-opt-detective
Linux~/.config/mag-opt-detective/mag-opt-detective.conf

After an update that changes what the stored settings mean, the app starts once from the defaults; your figure presets stay.

The font cache

The standalone app keeps matplotlib's font cache, which the first journal figure builds, in:

SystemCache
macOS~/Library/Caches/mag-opt-detective
Windows%LOCALAPPDATA%\mag-opt-detective
Linux~/.cache/mag-opt-detective (or under $XDG_CACHE_HOME)

It can be deleted at any time; it is built again when needed.

Files read

FileContent
OPUS binary (*.0, *.1, …)Bruker OPUS files; the single-channel sample spectrum (ScSm) is read
Text (*.txt, …)two columns separated by spaces or tabs: wavenumber in cm⁻¹, intensity; Windows line ends and a falling wavenumber order are fine
Data tablesmaps in the data table format, loaded into the library
Point tablespicked points in the point table format, imported in the Points panel

The field of a spectrum comes from its file name, _a01p250T for 1.25 T (the last such tag counts), or from a custom range (details).

Files written

Every table is plain text with tab-separated columns. Energies are written in the unit shown, and the first header cell names it: Energy (cm-1), Energy (meV) or Energy (THz).

Data tables

Export › Data table… (Ctrl+E) writes the map shown: one row per energy, one column per field. The library loads these tables back; one without the unit in the first header cell is read in the unit shown.

Energy (meV)	0.25T	0.50T	...
12.5	1.0012	0.9987	...
12.6	1.0009	0.9991	...

Without a typed extension the file gets .csv. With Add plot type to the file name, the plot is appended to the name, e.g. sweep_Ratio_1stDer_perUnit.csv.

Point tables

Points › Export… writes one row per field (in T, first column) and one column per curve, with empty cells where a curve has no point:

Energy (meV)	LL 1	LL 2
0.5	12.398
1.0		24.797

Tables without the unit in the first header cell are read in the unit shown.

Fit results

Export… in a model's fit area writes # lines that describe the fit (model, assignment of the curves, number of points and degrees of freedom, χ² and reduced χ², and the model's structure), then one row per parameter, in the unit shown. Fixed parameters have an empty sigma. The Dirac fit from the Models page, in meV:

# Model: Massive Dirac
# Assignment: branch; LL 1 -> L0 → L1, LL 2 -> L−1 → L2, CR -> L−2 → L3
# Points: 37; dof: 35
# chi2: 12.0345 meV^2; reduced chi2: 0.343844 meV^2
# Transitions: 3
parameter	value	sigma	unit
v	5.401338712	0.004850277148	1e5 m/s
Delta	11.95053795	0.120455638	meV

Copy puts the same table on the clipboard.

Figures

  • Journal figures (PDF, SVG, EPS, PNG, TIFF) have the exact print size; PDF, SVG and EPS keep their text editable, PNG and TIFF store their dpi. See Journal figures.
  • Quick images (PNG, SVG) show the plot as it is on screen, with its colour scale.
