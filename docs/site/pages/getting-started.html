Getting started

A session usually runs in one direction: open a sweep, process it, look at the maps, pick the transitions, fit a model and export. This page covers the first two steps and the window.

Open a sweep

A sweep is one spectrum per magnetic field plus one or two spectra at zero field. Open it with Open sweep… in the toolbar (Ctrl+L), or drop the sweep folder or its files on the Sample panel. A drop replaces the files the panel had; files whose first field is 0 T go to the zero-field list, the others to the field list.

File types

The type of each file is detected automatically:

FileWhat is read
OPUS binary (*.0, *.1, …)the single-channel sample spectrum (ScSm)
Text (*.txt, …)two columns separated by spaces or tabs, as the OPUS export macro writes them: wavenumber in cm⁻¹, intensity

The field of each file

With Field values › From file names (the default) the field is read from the name: _a01p250T means 1.25 T, so Demo_4p2K_Sam1_a01p250T.txt is the spectrum at 1.25 T. The files are sorted by field, and the panel lists each file with its field, shows the part of the names they share, and reports fields that are missing from the steps.

If the names hold no field, choose Custom range and type the first field, the step and the last field in tesla; the files are then taken in the order of their names.

Zero field

Load one zero-field spectrum, or two: one measured before and one after the sweep. With two, the zero-field reference is interpolated linearly between the first and the last field point, which corrects a drift during the sweep. The names of a sweep up to 16 T might look like this:

Demo_4p2K_Sam1_a00p000T_a00p000T.txt    zero field, before the sweep
Demo_4p2K_Sam1_a00p250T.txt             0.25 T
Demo_4p2K_Sam1_a00p500T.txt             0.5 T
…
Demo_4p2K_Sam1_a16p000T.txt             16 T
Demo_4p2K_Sam1_a00p000T_a16p000T.txt    zero field, after the sweep up to 16 T

Load sample zero field… (Ctrl+Shift+L) adds zero-field files by hand. A reference sweep, for example of the bare substrate, goes into the Reference panel the same way (Ctrl+R and Ctrl+Shift+R); see Processing.

Watch a running measurement

While a sweep is being measured, the app can follow its folder and add each new spectrum as it appears. After opening a sweep folder, turn on Watch for new files under Watch folder at the bottom of the Sample panel, or in the File menu; it adds every complete spectrum of the folder that is not listed yet. For a folder that may still be empty, choose Watch a folder… there or in the File menu: it replaces the files the panel had, and the first files that arrive start the sweep. New files go into the lists as when the folder is dropped.

A file counts once its size has not changed for about 2 seconds, it reads as a spectrum and its energy axis is the sweep's. A file that keeps failing these checks, or that has no field in its name (with From file names), is left out and reported once; files left out together are reported in one message. A spectrum deleted from the folder leaves the lists, and comes back when it is written again. Each update reads only the new files and processes the sweep with the current processing settings, as Process does, at most about once a second. Picked points, ranges and colour levels stay, and the point table gets rows for the new fields. Nothing is processed until a zero-field spectrum is there. With only the one measured before the sweep, that spectrum is used for the whole sweep; drift correction starts when the one after the sweep arrives. With a custom field range, the sweep is processed once there are as many files as values in the range, and while a library map is shown new files are only listed.

The Sample panel and the status bar show the folder, the number of files and the time of the last update. If the folder cannot be read for a while (a network drive), they say since when, and watching goes on when it is back. The switch, or × in the status bar, stops watching; the files and the map stay. The reference sweep is not watched, and watching never resumes after a restart.

Process

Press Process in the toolbar (Ctrl+Return or Ctrl+F). The map of the sweep appears, and the status bar reads Processed with the time.

Processing settings take effect the next time you process. When one has changed since the last run, a dot appears on the Process button and on the Process rail button, and the status bar says Settings changed · process again. The choices of what to show (plot, derivative, unit, ranges, colours) apply at once and need no processing.

On macOS

Ctrl is ⌘ and Alt is ⌥ in every shortcut on this site.

The window

The window is a workbench: every side area slides open and closed, its dividers can be dragged, and the layout is remembered.

Toolbar
Open sweep… and Process; the Plot (R(B)/R(0), Data, R(B)/R(B-AVR), R(B)/R(B-ΔB)); the Derivative (Off, 1st, 2nd, along d/dE or d/dB, per data point or per unit); the Unit (cm⁻¹, meV, THz); the Export menu; and the appearance button (system, light or dark).
Rail and panels
One panel per step: Sample, Reference (the rail says Ref), Process (the Processing panel), Library and Points. A click on a rail button opens its panel; a second click closes it. The Sample and Ref icons show the state of their files: an outline when there are none, a dot when they are not processed yet or changed since the last Process, and filled when the last Process used them as they are. With The sample as reference, Ref follows the sample; with None it stays an outline.
Plot tabs
Map (the colour map), Stacked (the spectra above one another) and Reference (the map the sample is divided by). The description next to the tabs names what is shown, e.g. R(B)/R(0) · 1st derivative d/dB per T.
Plot tools
Pan and zoom (V), Box zoom (Z), Pick points (P) and Auto-pick (W); Fit to data (A); the switch between classic and slim colour scales; Auto-scale the histograms; showing or hiding all colour scales and the inspector; and a quick PNG or SVG image of the plot.
Inspector
Settings for the plot on screen: View (field, energy and intensity ranges), Colour (colour map and levels), Traces (stacked plot) and Models (map). Its sections follow the plot tab and fold away.
Status bar
Whether the map is processed, changed since the last run or a library map; the folder being watched, if any; its baseline region, if it has one (a click opens it in the Processing panel); a summary such as 64 spectra · B 0.25 – 16 T · E 350 – 3200 cm⁻¹; the field and energy under the cursor; and the Log button, with the number of new errors.
Log
A drawer below the plot with what the app did: files loaded, processing, fits, exports and errors.

When something cannot be done, a bar above the plot says what failed and why, for example Can't process: …, with a button that opens the panel where it can be fixed. Unexpected errors also go into the log.
