Processing

Process turns the loaded spectra into maps of intensity over field and energy. Its settings live in the Sample, Reference and Processing panels and take effect the next time you process (the baseline can also apply at once, see Baseline).

What Process does

  1. Read. Every spectrum is read in cm⁻¹, the unit of the files. If the Processing panel has an energy window, the data outside it is dropped first.
  2. Divide by zero field. Each in-field spectrum R(B) is divided by the zero-field spectrum R(0). With two zero-field spectra, R(0) is interpolated linearly between the first and the last field point, so a drift during the sweep cancels.
  3. Correct with a reference, if one is chosen in the Reference panel (see below).
  4. Build the plot kinds listed below, and shift the ratio maps to the baseline, if one is set.

Derivatives, the energy unit, ranges and colours are applied when a map is shown, so changing them never needs processing again.

The plot kinds

Choose them with Plot in the toolbar or with Ctrl+1 to 4:

PlotEach spectrum is
R(B)/R(0)divided by the zero-field spectrum; the usual view of a sweep
Datashown as measured, or divided by the reference when one is used
R(B)/R(B-AVR)divided by the average of all spectra of the sweep, which brings out what changes with the field without a zero-field spectrum
R(B)/R(B-ΔB)R(B)/R(0) divided by the one at the previous field step, so only the change from one field to the next remains; it needs at least two fields

Reference correction

The Reference panel divides out what the sample's spectra share with another measurement:

None
The sample ratio is used as measured.
Separate sweep
Divides by a second sweep measured the same way, for example of the bare substrate. Load it like the sample: Open reference sweep… (Ctrl+R), zero field with Ctrl+Shift+R, or a drop on the panel. Its fields come from its file names, or from its own custom range when the sample uses one. The reference is interpolated onto the sample's fields (and onto its energies, if they differ) before dividing: the sample's data by the reference's data, and the sample's R(B)/R(0) by the reference's R(B)/R(0). Without reference files, Process shows the sample as with None and says so in a note above the plot; reference files that cannot be read stop Process with an error.
The sample
Divides the sweep by itself, smoothed, to remove slow spectral features while keeping the narrow lines. Use it with smoothing on.

Smooth the reference applies a Savitzky–Golay filter along energy before dividing. The window (in points, default 11) must be odd and larger than the polynomial order (default 2). The Reference plot tab shows the reference map the sample is divided by, as R(B)/R(0) or as data.

Energy window

The Energy window in the Processing panel drops the data outside it, for example the noisy edges of a detector range. Type its ends in the unit shown; an empty end leaves that side open. The window changes the data, so it applies when you process.

To look at a smaller range without changing the data, use the energy range in inspector › View instead (the panel links to it): it keeps the data and changes only the view. See Viewing.

Baseline

With Baseline on, each spectrum of the ratio maps (R(B)/R(0), R(B)/R(B-AVR) and R(B)/R(B-ΔB)) is shifted so that its average over the baseline region is 1. Choose a region without features, where the ratio should be flat. The data map is not shifted.

While the Processing panel is open, the map and the stacked plot show the region as a band. Drag the band to move it, or drag an edge (by the handle in its middle) to resize it. It stays inside the data, or inside the energy window when that is on. The fields follow the band in the unit shown, and typing in them moves the band. Edit on plot keeps the band on the plots when the panel is closed. If you switch the baseline on with both fields empty, the region starts over the lowest tenth of the energies.

A new region applies the next time you process. With Live on, it applies at once, while you drag or type, without processing again: the maps of the last Process are shifted to the new region, and the points, ranges and colours stay. On a large map, where one update takes longer than a tenth of a second, it applies when you let go of the band. Live leaves a map from the library as it is, since that map keeps the baseline it was plotted with.

Custom field range

When the file names hold no field, set Field values › Custom range in the Sample panel: the first field, the step and the last field in tesla. The range must have one field per in-field file; if it does not, Process stops and says how many of each there are. A reference sweep then takes its own custom range, set in the Reference panel.

Units in processing

The energy window and the baseline are typed in the unit shown in the toolbar, but they are kept in cm⁻¹: switching the unit converts the numbers in the fields and changes nothing in the result.
